To make the text bigger, use your terminal's own zoom keys: <kbd>Ctrl</kbd>+<kbd>=</kbd> and <kbd>Ctrl</kbd>+<kbd>-</kbd> in most terminals (<kbd>Cmd</kbd>+<kbd>+</kbd> / <kbd>Cmd</kbd>+<kbd>-</kbd> on macOS). Skink runs inside your terminal and draws in its font, so the font size is the terminal's to set. Skink leaves those keys unbound so they keep working.

If you want more room for the text rather than bigger letters, press <kbd>Alt</kbd>+<kbd>Z</kbd> or <kbd>F5</kbd> to zoom the pane.

## Font size

| Terminal | Bigger / smaller / reset |
|---|---|
| Most Linux terminals, Windows Terminal | <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> / <kbd>Ctrl</kbd>+<kbd>0</kbd> |
| macOS terminals | <kbd>Cmd</kbd>+<kbd>+</kbd> / <kbd>Cmd</kbd>+<kbd>-</kbd> / <kbd>Cmd</kbd>+<kbd>0</kbd> |

Check your terminal's docs if these differ. The font itself, including the Nerd Font for icons, is also chosen in your terminal's settings.

### :fontsize

Some terminals let a program change the font size. For those, Skink has a command:

```text
:fontsize +1     bigger
:fontsize -1     smaller
:fontsize 0      back to the default
```

`:font` is the short form. The matching actions are `FontBigger`, `FontSmaller` and `FontReset`, which you can bind to keys.

It works in two places:

- **Kitty**, when remote control is allowed. Add `allow_remote_control yes` to `kitty.conf` (or a more restricted value Kitty accepts). Without it, Skink reports that Kitty refused.
- **EveryAI**, when Skink runs inside it. See [EveryAI](/skink/guides/everyai/).

Elsewhere, use the terminal's keys.

## Zoom pane

<kbd>Alt</kbd>+<kbd>Z</kbd>, <kbd>F5</kbd> or `:zoom` shows only the text: the tab bar, the file tree and the status line disappear. The status line comes back while a prompt or message is up. Press the same key again to bring everything back.

<kbd>F5</kbd> and `:zoom` are there because <kbd>Alt</kbd> chords can be awkward on macOS. See [macOS Option key](/skink/guides/macos-option-key/).

<Aside type="tip" title="Everything disappeared?">
If the tab bar, tree and status line are gone, you are in zoom mode. Press <kbd>Alt</kbd>+<kbd>Z</kbd> or <kbd>F5</kbd>, or type `zoom` in the command line (<kbd>Ctrl</kbd>+<kbd>E</kbd>).
</Aside>

## Grow a split pane

With split panes, make the focused one bigger or smaller:

| Key | Does |
|---|---|
| <kbd>Alt</kbd>+<kbd>=</kbd> | Grow the focused pane |
| <kbd>Alt</kbd>+<kbd>-</kbd> | Shrink the focused pane |

Or drag the divider, or a pane's title row, with the mouse. See [Splits and docks](/skink/guides/splits-and-docks/).

## File tree width

With the file tree focused (<kbd>F8</kbd>), press <kbd>&lt;</kbd> to make it narrower and <kbd>&gt;</kbd> to make it wider. You can also drag its right border. The actions are `TreeNarrower` and `TreeWider`, so you can bind them to keys that work from the editor too.

To hide the tree entirely, press <kbd>Ctrl</kbd>+<kbd>B</kbd>. See [Hidden files and panels](/skink/guides/hidden-files-and-panels/).
