Press <kbd>Ctrl</kbd>+<kbd>D</kbd> to select the word under the cursor, then press it again to add a cursor at the next match. Type, and every cursor types. <kbd>Esc</kbd> goes back to a single cursor.

This works like Sublime Text and VS Code, with Micro's action names.

## Multiple cursor keys

| Key | Typed command | Does |
|---|---|---|
| <kbd>Ctrl</kbd>+<kbd>D</kbd> or <kbd>Alt</kbd>+<kbd>N</kbd> | `:addcursor` | Select the word; again: add a cursor at the next match |
| <kbd>Alt</kbd>+<kbd>X</kbd> | `:skipcursor` | Skip this match and select the next one |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | `:cursorabove` / `:cursorbelow` | Add a cursor on the line above / below |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | same | An alternative binding for the same |
| <kbd>Alt</kbd>+click | | Add a cursor, or remove the one under the mouse |
| <kbd>Esc</kbd> or <kbd>Alt</kbd>+<kbd>C</kbd> | `:onecursor` | Back to one cursor |

The status line shows **×N** while you have N cursors.

<Aside type="tip" title="Alt chords not arriving?">
On macOS or inside tmux, <kbd>Alt</kbd>+<kbd>Shift</kbd>+arrow chords often get lost. Press <kbd>Ctrl</kbd>+<kbd>E</kbd> and type the command instead, for example `cursorbelow`. See [Typed commands](/skink/start/typed-commands/).
</Aside>

## What happens at every cursor

- Typing, deleting, moving, indenting and moving lines (<kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd>).
- Case changes, join, sort and trim (`:UpperCase`, `:LowerCase`, `:TitleCase`, `:JoinLines`, `:SortLines`, `:TrimTrailingWhitespace`).
- One undo (<kbd>Ctrl</kbd>+<kbd>Z</kbd>) undoes the change at all cursors.

## Copy and paste with several cursors

- Copy with N cursors puts one line per cursor on the clipboard.
- Pasting N lines into N cursors gives each cursor its own line.

So you can copy five values from five places and paste them into five other places in one go.

## Examples

### Rename a variable within a function

Put the cursor on the name and press <kbd>Ctrl</kbd>+<kbd>D</kbd> once to select it. Press it again for each use you want, and <kbd>Alt</kbd>+<kbd>X</kbd> to skip a match you do not want. Type the new name.

For a rename across files that understands your code, use the language server instead: <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>R</kbd>. See [Refactoring](/skink/guides/refactoring/).

### Add a comma at the end of ten lines

Put the cursor on the first line and press <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>↓</kbd> nine times. Press <kbd>End</kbd>, then type `,`.

### Edit every match in the file at once

For a plain replace-all, the find bar is quicker: <kbd>Ctrl</kbd>+<kbd>F</kbd>, type, <kbd>Tab</kbd>, type the replacement, <kbd>Enter</kbd>. See [Find and replace](/skink/guides/find-and-replace/).

## Bind the multiple cursor actions

The actions use Micro's names, so they can be bound in `bindings.json`:

| Action | Does |
|---|---|
| `SpawnMultiCursor` | Select the word, then add a cursor at the next match |
| `SpawnMultiCursorUp` / `SpawnMultiCursorDown` | Add a cursor above / below |
| `SkipMultiCursor` | Skip this match and select the next |
| `RemoveMultiCursor` | Remove the newest cursor |
| `RemoveAllMultiCursors` | Back to a single cursor |

For example, to remove the newest cursor with <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> (Micro's format writes Shift as a capital letter):

```json
{ "Alt-X": "RemoveMultiCursor" }
```

See [Key bindings](/skink/guides/keybindings/).
