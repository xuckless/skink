Skink gets completion, errors, go to definition and the rest from language servers. Install the server for your language and put it on your `PATH`. Skink starts it the first time you open a file of that language, with no config. Then <kbd>Ctrl</kbd>+<kbd>Space</kbd> completes, <kbd>Alt</kbd>+<kbd>G</kbd> goes to the definition and <kbd>Alt</kbd>+<kbd>R</kbd> lists references.

## Which language servers

| Language | Server Skink looks for | One way to install it |
|---|---|---|
| Rust | `rust-analyzer` | `rustup component add rust-analyzer` |
| TypeScript, JavaScript | `typescript-language-server` | `npm i -g typescript-language-server typescript` |
| Python | `basedpyright-langserver`, else `pyright-langserver` | `pip install basedpyright` or `npm i -g pyright` |
| Go | `gopls` | `go install golang.org/x/tools/gopls@latest` |
| Zig | `zls` | Your package manager, or a release from the zls project |
| Dart | `dart language-server` | Comes with the Dart (or Flutter) SDK |

Other languages get syntax colours and every editing feature, but no language server yet. The server list is built in; you cannot add your own servers in settings.

`:lsp` shows the server for the current file, its memory use and progress. If the server is missing, it says which program it looked for.

- `:lsp restart` restarts it.
- `:lsp log` shows its full log.

A server that crashes is restarted once automatically. One with no open files for 10 minutes is stopped and starts again when you need it, which keeps memory low.

## Keys

| Key | Command | Does |
|---|---|---|
| <kbd>Ctrl</kbd>+<kbd>Space</kbd> | | Completion list |
| <kbd>Alt</kbd>+<kbd>K</kbd> | | Type and docs of the symbol at the cursor |
| <kbd>Alt</kbd>+<kbd>G</kbd> | `:definition` (`:def`) | Go to definition (several: a list) |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> | | Go to the type's definition |
| <kbd>Alt</kbd>+<kbd>J</kbd> | | Peek the definition in a popup |
| | `:implementation` (`:impl`) | Go to implementations |
| <kbd>Alt</kbd>+<kbd>R</kbd> | `:references` (`:refs`) | Every use, in a results tab (<kbd>Enter</kbd> jumps) |
| <kbd>Alt</kbd>+<kbd>Enter</kbd> | | Code actions: quick fixes and refactorings |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>R</kbd> | `:renamesymbol NEW` (`:rn`) | Rename the symbol everywhere |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> | `:format` (`:fmt`) | Format the selection or the file |
| <kbd>Ctrl</kbd>+<kbd>R</kbd> | `:symbols` | Symbols in this file |
| <kbd>Alt</kbd>+<kbd>W</kbd> | | Symbols in the whole project |
| <kbd>F9</kbd> | `:problems` | Errors and warnings of the open files |
| <kbd>F6</kbd> / <kbd>Shift</kbd>+<kbd>F6</kbd> | | Next / previous error or warning in this file |
| <kbd>Alt</kbd>+<kbd>U</kbd> / <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>U</kbd> | `:back` / `:forward` | Back to where you were before a jump, and forward again |

## Completion

The list opens by itself after two letters or after `.`, `::` or `->`. <kbd>↑</kbd> / <kbd>↓</kbd> choose, <kbd>Enter</kbd> or <kbd>Tab</kbd> insert, <kbd>Esc</kbd> closes. Docs for the selected item show beside the list. Snippets select their first placeholder; <kbd>Tab</kbd> moves to the next one.

Do not want it popping up? Set `"autocomplete": false`. <kbd>Ctrl</kbd>+<kbd>Space</kbd> still works.

Signature help opens after `(` and `,`, showing the parameters of the call you are typing.

## Errors and warnings

Diagnostics show in the gutter and as red and yellow marks on the scrollbar (the editor's last column). <kbd>F6</kbd> steps through them, <kbd>F9</kbd> lists all of them in a tab. A lightbulb in the sign column means the cursor line has code actions: press <kbd>Alt</kbd>+<kbd>Enter</kbd>.

To send the errors to an AI agent, press <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd>. See [AI agents](/skink/guides/ai-agents/).

## Format on save

```json
{ "formatonsave": true }
```

With this, <kbd>Ctrl</kbd>+<kbd>S</kbd> asks the language server to format the file first. <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> formats on demand.

## Inlay hints

```json
{ "inlayhints": true }
```

shows the server's inline type and parameter hints. They are off by default.

## Rename and other multi-file edits

Rename (<kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>R</kbd>) and code actions that touch several files open the refactor preview, where you check which changes to apply. See [Refactoring](/skink/guides/refactoring/).

## Breadcrumbs and quick open

The status line shows where the cursor is, like `impl Foo > fn bar`. Quick open (<kbd>Alt</kbd>+<kbd>P</kbd>) switches mode by its first character: `@` for symbols in the file, `#` for symbols in the project, `>` for commands.

## When nothing happens

- Run `:lsp`. If it says the server is not installed, install it and make sure your shell's `PATH` has it, then `:lsp restart`.
- Files of 2 MB or more open as LARGE, without a language server.
- Over SSH, the server has to be installed on the server.
- Inside [EveryAI](/skink/guides/everyai/), language servers come from EveryAI instead.
