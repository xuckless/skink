The mouse works in Skink without any setup. Click to place the cursor, drag to select, scroll with the wheel. <kbd>Alt</kbd>+click adds another cursor, and <kbd>Shift</kbd>+wheel or a sideways trackpad swipe scrolls long lines.

## In the editor

| Do this | Gets you |
|---|---|
| Click | Move the cursor there |
| Drag | Select |
| <kbd>Alt</kbd>+click | Add a cursor there, or remove one that is there |
| Wheel | Scroll three lines at a time |
| <kbd>Shift</kbd>+wheel | Scroll sideways |
| Trackpad swipe left / right | Scroll sideways |

Sideways scrolling moves the text but keeps the line numbers in place. The view stays scrolled until the cursor moves. When lines are wider than the view, a thin thumb on the bottom row shows where you are. Keyboard users can bind `ScrollLeft` and `ScrollRight`.

## Clickable parts of the window

| Click | Does |
|---|---|
| A tab | Switch to it |
| A tab's `x`, or middle-click a tab | Close it (asks first if it has unsaved changes) |
| A fold mark in the gutter | Open the fold |
| A git change mark in the gutter | Peek at the change: <kbd>s</kbd> stage, <kbd>u</kbd> unstage, <kbd>r</kbd> revert, <kbd>Esc</kbd> |
| A sticky header at the top | Jump to that block's first line |
| "Accept ours \| theirs \| both" on a merge conflict | Resolve that conflict block |
| A pane | Focus it |
| The file tree | Focus the tree (clicking the editor or a tab hands the keys back) |

## Resizing with the mouse

- **Split panes**: drag the divider between two panes, or drag a pane's title row.
- **File tree**: drag its right border.

The keyboard equivalents are <kbd>Alt</kbd>+<kbd>=</kbd> / <kbd>Alt</kbd>+<kbd>-</kbd> for panes and <kbd>&lt;</kbd> / <kbd>&gt;</kbd> in the tree. See [Splits and docks](/skink/guides/splits-and-docks/).

## In terminal tabs

- Programs that use the mouse, such as `htop`, `lazygit` or an AI CLI, get your clicks and the wheel.
- Otherwise the wheel scrolls the terminal's scrollback.
- <kbd>Ctrl</kbd>+click on a `file:line[:col]` in the output opens that file at that line.

See [Terminal tabs](/skink/guides/terminal-tabs/).

## Selecting text the terminal way

Skink captures the mouse, so a plain drag selects inside Skink rather than in your terminal. Most terminals let you hold <kbd>Shift</kbd> (on macOS often <kbd>Option</kbd> or <kbd>Fn</kbd>, depending on the terminal) while dragging to bypass that and use the terminal's own selection. Inside Skink, prefer <kbd>Ctrl</kbd>+<kbd>C</kbd>: it also reaches your clipboard over SSH.

<Aside type="note">
There is no double-click to select a word yet. Use <kbd>Ctrl</kbd>+<kbd>D</kbd> to select the word at the cursor, and <kbd>Alt</kbd>+<kbd>O</kbd> to grow the selection to the enclosing syntax node.
</Aside>

## Mouse not working?

- Over `tmux`, mouse events reach Skink only if tmux passes them on. Check your tmux `mouse` setting.
- Some very old terminals do not report the mouse at all. Ghostty, Kitty, WezTerm, iTerm2, Windows Terminal, GNOME Terminal and Alacritty all do.
