Neovim is a modal, endlessly configurable editor with a huge plugin ecosystem. Skink is a modeless terminal editor that ships the IDE parts (language servers, tree-sitter, git, a terminal tab, AI agents) built in, with Micro / VS Code style keys and full mouse support. If you like modes and enjoy building your own setup, stay on Neovim. If you want the terminal workflow without modes or a config project, try Skink.

## Who should pick Neovim

- You think in Vim motions and text objects (`ciw`, `dap`, `.`) and do not want to give them up.
- You want plugins. Neovim's Lua ecosystem covers almost anything: debuggers through nvim-dap, fuzzy finders, note systems, language-specific tooling. Skink has **no plugins or scripting yet**.
- You need a debugger today. Skink has no DAP support yet; it is planned for v0.8.
- You want something mature. Neovim has been in daily use by a large community for over a decade. Skink is **alpha**.

## Who should pick Skink

- You want to work in the terminal, over SSH, keyboard-driven, but without switching between Normal and Insert mode.
- You want the mouse to behave like in a GUI editor: click to place the cursor, drag to select, Alt-click for more cursors, click tabs, drag split dividers, scroll sideways with Shift+wheel or a trackpad swipe.
- You want LSP, completion, rename, code actions, git hunks and blame, project search and an AI agent panel working on first start, without assembling them from plugins.
- You want one small static binary you can drop on any server.

## Feature comparison

| | Skink | Neovim |
|---|---|---|
| Editing model | Modeless (Micro / VS Code keys) | Modal (Vim) |
| Mouse | On, always; click, drag, multi-cursor, tabs, dividers | On by default since 0.8 (`mouse=nvi`) |
| LSP | Built in, servers start on first use | Built-in client; servers configured by you (or a plugin) |
| tree-sitter | Built in, 19 languages compiled in | Built in; parsers installed per language |
| Built-in terminal | Yes, as tabs and a bottom dock | Yes, `:terminal` |
| AI agents | ACP client, agent panel, prompt box with inline diff review | Through plugins |
| Plugins | None yet | Large Lua and Vimscript ecosystem |
| Debugger (DAP) | Not yet | nvim-dap plugin |
| Works over plain SSH | Yes | Yes |
| Footprint | Small (one static binary) | Small core; grows with plugins |
| Maturity | Alpha | Mature |

## What you give up, honestly

Neovim's strength is that it becomes exactly your editor. Every key, every panel, every workflow can be changed with Lua. Skink's keys and settings are configurable in JSON, but you cannot add new behaviour yet. If you rely on a specific plugin (a test runner UI, a REPL bridge, org-mode style notes), check that Skink covers it before switching.

Skink also has no Vim emulation and no plan for one. If you want modal editing with built-in IDE features, look at [Helix](/skink/compare/helix/).

## What you get without configuring anything

- **Language servers** for Rust, TypeScript/JavaScript, Python, Go, Dart and Zig start when you open a file of that language, if the server is installed. Completion, hover (<kbd>Alt</kbd>+<kbd>K</kbd>), go to definition (<kbd>Alt</kbd>+<kbd>G</kbd>), references (<kbd>Alt</kbd>+<kbd>R</kbd>), code actions (<kbd>Alt</kbd>+<kbd>Enter</kbd>), rename across files through a preview with checkboxes.
- **Git**: gutter marks, stage or revert a hunk, inline blame, a git panel (<kbd>Alt</kbd>+<kbd>C</kbd>), side-by-side diff, clickable merge-conflict resolution.
- **Terminal tabs**: <kbd>F12</kbd> flips between your file and a shell, <kbd>Shift</kbd>+<kbd>F12</kbd> opens another. They are real terminal emulators, so `htop`, `lazygit` or `claude` run unchanged.
- **AI agents** over the Agent Client Protocol: Claude Code, Gemini CLI, opencode, Goose, Codex and others. See [AI agents](/skink/guides/ai-agents/).

## Switching tips for Neovim users

The keys follow Micro, which follows common desktop editors. The ones you will reach for first:

| You did in Neovim | In Skink |
|---|---|
| `:w` | <kbd>Ctrl</kbd>+<kbd>S</kbd> (or <kbd>Ctrl</kbd>+<kbd>E</kbd> then `w`) |
| `:q` | <kbd>Ctrl</kbd>+<kbd>Q</kbd> (or <kbd>Ctrl</kbd>+<kbd>E</kbd> then `q`) |
| `u` / `Ctrl-r` | <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Y</kbd> |
| `/pattern` | <kbd>Ctrl</kbd>+<kbd>F</kbd>, then <kbd>Ctrl</kbd>+<kbd>N</kbd> / <kbd>Ctrl</kbd>+<kbd>P</kbd> |
| `v`, `V` | <kbd>Shift</kbd>+arrows, or drag with the mouse |
| `gd` | <kbd>Alt</kbd>+<kbd>G</kbd> |
| `K` | <kbd>Alt</kbd>+<kbd>K</kbd> |
| `Ctrl-o` (jump back) | <kbd>Alt</kbd>+<kbd>U</kbd> |
| Telescope find files | <kbd>Alt</kbd>+<kbd>P</kbd> or <kbd>Ctrl</kbd>+<kbd>P</kbd> |
| live grep | <kbd>Alt</kbd>+<kbd>S</kbd> or <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> |
| `:vsplit` / `:split` | <kbd>Ctrl</kbd>+<kbd>\\</kbd> / <kbd>Alt</kbd>+<kbd>\\</kbd> (also `:vsplit`, `:split`) |
| `q` / `@` macros | <kbd>Ctrl</kbd>+<kbd>U</kbd> records, <kbd>Ctrl</kbd>+<kbd>J</kbd> replays |
| `:terminal` | <kbd>Shift</kbd>+<kbd>F12</kbd> or `:term` |

Many commands keep their Vim names in the command line (<kbd>Ctrl</kbd>+<kbd>E</kbd>): `:w`, `:q`, `:e FILE`, `:vs`, `:sp`, `:only`, `:goto`. The full list is in [shortcuts](/skink/reference/shortcuts/).

If you miss a binding, add it to `~/.config/skink/bindings.json`:

```json
{
  "Alt-w": "Save",
  "Ctrl-5": "JumpToMatchingBrace"
}
```

<Aside type="tip">
On macOS, set your terminal to send Option as Alt, or let Skink translate Option characters (the default `"macoptionisalt": "auto"`). Many Skink shortcuts use Alt.
</Aside>

## Try it

```sh
curl -fsSL https://github.com/xuckless/skink/releases/latest/download/install.sh | sh
skink .
```

It installs to `~/.local/bin` without sudo, and you can keep Neovim installed side by side. Next: [quick start](/skink/start/quick-start/), or read [a Neovim-style editor without modes](/skink/articles/modeless-editor-for-vim-users/).
