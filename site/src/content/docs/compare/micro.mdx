Skink started from Micro. It uses Micro's default key bindings and the same `settings.json` and `bindings.json` formats, so your muscle memory carries over.

The difference is what is built in. Skink ships language servers, tree-sitter, git, project search, terminal tabs and an AI agent client. Micro keeps a small core and adds features through Lua plugins.

## Who should pick Micro

- **Plugins.** You use Micro plugins or write your own in Lua. Skink has **no plugins or scripting yet**.
- **Maturity.** Micro has been around since 2016. Skink is alpha.
- **Micro's own formats.** You like Micro's syntax files and colorschemes and want to keep customising them.
- **Minimalism.** You want the smallest feature set that does the job.

## Who should pick Skink

- **IDE features without plugins.** You love Micro's keys but want completion, hover, go to definition, rename, code actions and formatting out of the box.
- **Syntax-aware editing.** Tree-sitter highlighting, syntax-aware selection (<kbd>Alt</kbd>+<kbd>O</kbd> / <kbd>Alt</kbd>+<kbd>I</kbd>) and folding.
- **Git in the editor.** Gutter marks, stage and revert hunks, blame, a git panel and conflict resolution.
- **AI agents.** You run AI coding agents and want them in the editor, not just next to it.

## Bring your Micro config over

Skink reads the same file formats from its own folder, `~/.config/skink` (or `$SKINK_CONFIG_DIR`). It does not read `~/.config/micro` by itself, so copy the files over:

```sh
mkdir -p ~/.config/skink
cp ~/.config/micro/settings.json ~/.config/micro/bindings.json ~/.config/skink/
```

Then run `:reload` inside Skink, or restart it.

### What carries over

- **bindings.json** uses Micro's key names and action names, including chains. `"Copy|CopyLine"` runs the first that works, `"Escape,Deselect"` runs both, and `"command-edit:goto "` opens the command line pre-filled.
- **settings.json** accepts Micro's options where Skink has the same feature, for example `tabsize`, `tabstospaces`, `autoclose` and `colorcolumn` (Skink also has `rulers`). Options for features Skink lacks have no effect.
- **Comments.** Skink also accepts `//` comments and trailing commas in both files.
- **Not supported.** Bindings that call Micro plugin actions or Lua do nothing.

```json
{
  "Ctrl-j": "Save",
  "Alt-g": "command-edit:goto ",
  "Ctrl-c": "Copy|CopyLine"
}
```

As in Micro, a capital letter after `Alt-` in bindings.json means Shift: `"Alt-G"` is <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd>.

<Aside type="note">
Micro's mouse bindings are not used. Skink handles the mouse directly: click, drag, <kbd>Alt</kbd>+click for cursors, middle-click to close a tab.
</Aside>

## Keys that are the same

Everything from Micro's defaults works as before:

- <kbd>Ctrl</kbd>+<kbd>S</kbd> save, <kbd>Ctrl</kbd>+<kbd>Q</kbd> quit
- <kbd>Ctrl</kbd>+<kbd>F</kbd> find, <kbd>Ctrl</kbd>+<kbd>N</kbd> / <kbd>Ctrl</kbd>+<kbd>P</kbd> next / previous match
- <kbd>Ctrl</kbd>+<kbd>E</kbd> command line
- <kbd>Ctrl</kbd>+<kbd>D</kbd> multiple cursors
- <kbd>Ctrl</kbd>+<kbd>U</kbd> / <kbd>Ctrl</kbd>+<kbd>J</kbd> record / replay a macro
- <kbd>Alt</kbd>+<kbd>,</kbd> / <kbd>Alt</kbd>+<kbd>.</kbd> previous / next tab

## Keys that are new in Skink

| Key | Typed command | Does |
|---|---|---|
| <kbd>Alt</kbd>+<kbd>P</kbd> | `:recent` | Quick open: tabs, recent and project files |
| <kbd>F1</kbd> | `:palette` | Command palette |
| <kbd>F8</kbd> / <kbd>Ctrl</kbd>+<kbd>B</kbd> | `:files` / `:sidebar` | File tree / hide the sidebar |
| <kbd>F12</kbd> / <kbd>Shift</kbd>+<kbd>F12</kbd> | `:toggleterm` / `:newterm` | Toggle to the terminal / new terminal |
| <kbd>Alt</kbd>+<kbd>S</kbd> | `:grep` | Search in all files |
| <kbd>Alt</kbd>+<kbd>G</kbd>, <kbd>Alt</kbd>+<kbd>K</kbd>, <kbd>Alt</kbd>+<kbd>R</kbd> | `:def`, `:hover`, `:refs` | Definition, hover, references |
| <kbd>Ctrl</kbd>+<kbd>G</kbd> | `:ask` | AI prompt box for the selection |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> | `:gitpanel` | Git panel |

To run a typed command, press <kbd>Ctrl</kbd>+<kbd>E</kbd>, type the name and press <kbd>Enter</kbd>. Every key has one. See [typed commands](/editing/typed-commands/).
