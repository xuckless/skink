Run `:settings` to open `settings.json` in a tab. Change a value and save with <kbd>Ctrl</kbd>+<kbd>S</kbd>: saving applies it.

Keys live in `bindings.json` (`:bindings`). Both files use Micro's format, and a missing file is created with defaults when you open it.

## Where the files live

| OS | Folder |
|---|---|
| Linux, macOS | `$XDG_CONFIG_HOME/skink`, else `~/.config/skink` |
| Windows | `%APPDATA%\skink` |
| Any | `$SKINK_CONFIG_DIR` when set |

Try a config without touching yours: `SKINK_CONFIG_DIR=/tmp/try skink .`

## Checked when you save

Both files accept `//` comments and trailing commas. Opening or saving one checks it, and each problem is marked at its key, in the gutter and in the problems list (<kbd>Shift</kbd>+<kbd>F8</kbd>):

- bad JSON, wrong types and out-of-range values: errors, and that value is not used
- unknown keys: a warning with "did you mean", the rest still applies

Inside a key's quotes, completion offers every setting with its description.

## The main settings

```jsonc
{
  "colorscheme": "auto",     // :theme lists and previews the others
  "keymap": "micro",         // or "vscode", "sublime"
  "tabsize": 4,
  "tabstospaces": false,
  "rulers": [80, 100],
  "formatonsave": false,
  "inlineblame": true,
}
```

| Setting | Default | Does |
|---|---|---|
| `colorscheme` | `"auto"` | Theme name. `"auto"` picks Tokyo Night day or night from the terminal. See [Themes](/customize/themes/) |
| `keymap` | `"micro"` | Default keys: `"micro"`, `"vscode"` or `"sublime"`. See [Key bindings](/customize/keybindings/) |
| `tabsize` | `4` | Columns per tab, 1 to 16 |
| `tabstospaces` | `false` | Spaces in new files (existing files keep the indentation they use) |
| `autoclose` | `true` | Close brackets and quotes as you type |
| `syntax` | `true` | Syntax colours |
| `indentguides` | `true` | Faint lines at each indent level |
| `icons` | `"auto"` | `"auto"`, `"nerd"` or `"ascii"` |
| `rulers` | `[]` | Vertical lines at these columns. Micro's `colorcolumn` works too |
| `stickyscroll` | `true` | Keep the headers of the blocks you are in at the top |
| `autocomplete` | `true` | Open completions while typing (<kbd>Ctrl</kbd>+<kbd>Space</kbd> always works) |
| `formatonsave` | `false` | Format with the language server before saving |
| `inlayhints` | `false` | Inline type and parameter hints |
| `gitgutter` | `true` | Git change marks next to the line numbers |
| `inlineblame` | `true` | The cursor line's last commit, faded |
| `restoresession` | `true` | `skink` in a project reopens its last session |
| `terminal.shellintegration` | `true` | Prompt marks in terminal tabs. Your rc files are never edited |
| `macoptionisalt` | `"auto"` | See [macOS Option key](/customize/macos-option-key/) |
| `updates` | `"notify"` | `"notify"`, `"auto"` or `"off"`. See [Install](/start/install/) |

Settings for other areas have their own pages: `ai.*` in [AI agents](/tools/ai-agents/), `lsp.*` in [Code intelligence](/code/code-intelligence/), `remotes` and `ssh.autoforward` in [Editing over SSH](/remote/ssh-remote-editing/).

Line endings are per file: `:set eol=lf` or `:set eol=crlf` changes them on the next save.

## Per language

A section named after a language (`rust`, `python`, `go`, `typescript`, …) or an extension (`md`) applies only there:

```json
{
  "[python]": { "tabsize": 4, "rulers": [88] },
  "[rust]": { "formatonsave": true },
  "[md]": { "rulers": [] }
}
```

## Per project

`:settings project` opens `.skink/settings.json` in the project. Its keys override yours there, and saving it applies it.

Settings that start programs (`lsp.*` and the `ai.agent` command) wait until you trust the project, and Skink asks again when they change.

## Coming from Micro

```sh
mkdir -p ~/.config/skink
cp ~/.config/micro/settings.json ~/.config/micro/bindings.json ~/.config/skink/
```

- Micro's key names, action names and `|` / `,` chains work.
- `tabsize`, `tabstospaces`, `autoclose`, `syntax` and `colorcolumn` carry over. Other Micro settings are flagged as unknown; delete them.
- Micro colorschemes load as they are, from `~/.config/micro/colorschemes`.
- Micro's `command:` prefix is `command-edit:` in Skink. Micro's Lua plugins do not run; Skink has its own [Lua scripts](/customize/scripting/).
