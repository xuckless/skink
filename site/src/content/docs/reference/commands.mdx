Press <kbd>Ctrl</kbd>+<kbd>E</kbd> to open the command line, type a command and press <kbd>Enter</kbd>. <kbd>Tab</kbd> completes names and paths, <kbd>↑</kbd> and <kbd>↓</kbd> walk the history. You type the command in plain text; Skink shows the `:` on the left for you. That is why these docs write commands as `:quit` or `:grep`: type `quit` or `grep`. <kbd>F1</kbd> opens the same list as a searchable palette.
