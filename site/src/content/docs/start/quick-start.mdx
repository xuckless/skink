Run `skink` with a file or a folder, then type: there are no modes. <kbd>Ctrl</kbd>+<kbd>S</kbd> saves, <kbd>Ctrl</kbd>+<kbd>Q</kbd> closes the tab, and <kbd>Ctrl</kbd>+<kbd>E</kbd> opens the command line, where `help` explains everything else.

If you have used Micro, VS Code or nano, most keys already do what you expect. Skink uses Micro's default bindings.

## Open a file or folder

```sh
skink                    # empty scratch buffer
skink src/main.rs        # open a file
skink src/main.rs:42     # open it at line 42
skink src/main.rs:42:7   # line 42, column 7
skink .                  # open a folder: file tree on the left
```

The `path:line:col` form matches what compilers and `grep -n` print. You can paste a location straight from an error message.

### Pick up where you left off

Running plain `skink` inside a project reopens the files, splits and shells you had when you last quit there. A project is a folder with `.git`, `Cargo.toml`, `package.json`, `go.mod`, `pyproject.toml` or `build.zig`.

See [Sessions and folding](/skink/guides/sessions-and-folding/).

### Open more files from inside the editor

| Key | Does |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Open a file or folder by path |
| <kbd>Alt</kbd>+<kbd>P</kbd> (or `:recent`) | Quick open: open tabs first, then recent files, then every file in the project |
| <kbd>Ctrl</kbd>+<kbd>T</kbd> | New empty tab |

In quick open, type a few letters of the name.

## The ten keys you need

| Key | Does |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save |
| <kbd>Ctrl</kbd>+<kbd>Q</kbd> | Close the tab (quits on the last file tab) |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Y</kbd> | Undo / redo |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Ctrl</kbd>+<kbd>X</kbd> / <kbd>Ctrl</kbd>+<kbd>V</kbd> | Copy / cut / paste (no selection: the whole line) |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | Find in the file (<kbd>Ctrl</kbd>+<kbd>N</kbd> / <kbd>Ctrl</kbd>+<kbd>P</kbd> next / previous match) |
| <kbd>Ctrl</kbd>+<kbd>L</kbd> | Go to line |
| <kbd>Alt</kbd>+<kbd>P</kbd> | Quick open (or type `:recent`) |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | Command line |
| <kbd>F8</kbd> | File tree (show it, move focus, go back) |
| <kbd>F12</kbd> | Jump between your file and a terminal tab |

<kbd>Ctrl</kbd>+<kbd>P</kbd> is Find previous, as in Micro, not quick open.

### A few more that pay off quickly

| Key | Typed command | Does |
|---|---|---|
| <kbd>Shift</kbd>+arrows | | Select |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | `:selectall` | Select all |
| <kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>Alt</kbd>+<kbd>↓</kbd> | `:moveup` / `:movedown` | Move lines up / down |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | `:addcursor` | Select the word, again for a cursor at the next match |
| <kbd>Alt</kbd>+<kbd>/</kbd> | `:comment` | Comment / uncomment lines |
| <kbd>Alt</kbd>+<kbd>1</kbd> … <kbd>Alt</kbd>+<kbd>9</kbd> | | Jump to tab N |
| <kbd>F1</kbd> | `:palette` | Command palette: every action and command |

Why every key has a typed command: [Every key has a typed command](/skink/start/typed-commands/).

The full list is in [Keyboard shortcuts](/skink/reference/shortcuts/).

## The mouse works

Click to place the cursor, drag to select, scroll with the wheel. <kbd>Alt</kbd>+click adds another cursor.

Click a tab to switch to it. Click its `x`, or middle-click it, to close it.

More in [Mouse and trackpad](/skink/guides/mouse-and-trackpad/).

## The command line

Press <kbd>Ctrl</kbd>+<kbd>E</kbd> and type a command. The command line already shows the `:` these docs write, so you type only the name.

A few to start with:

| Command | Does |
|---|---|
| `:help` | The built-in manual in a tab. `:help tabs` or `:help settings` jump to a topic |
| `:goto 120` | Jump to line 120 |
| `:open PATH` | Open a file or folder |
| `:term` | A new terminal tab (`:term claude` runs a program in it) |
| `:run CMD` | Run a shell command, output in a tab |
| `:settings` | Open `settings.json` |

<kbd>Tab</kbd> completes command names and paths, <kbd>↑</kbd> / <kbd>↓</kbd> browse history, <kbd>Esc</kbd> cancels.

Any editor action can be run by name too, for example `:SelectAll` or `:Save`. All commands are listed in [Commands](/skink/reference/commands/).

## Everything is a tab

Skink has one tab bar for everything: files, terminals, the help manual, command output, git diffs, merge conflicts and your settings. Nothing opens a window you have to dismiss.

| Key | Does |
|---|---|
| <kbd>Shift</kbd>+<kbd>F12</kbd> | Open a terminal tab. It is a real terminal emulator, so shells, `htop` and AI CLIs run unchanged |
| <kbd>F12</kbd> | Flip between your file and your terminal |
| <kbd>Ctrl</kbd>+<kbd>PageUp</kbd> / <kbd>Ctrl</kbd>+<kbd>PageDown</kbd> | Previous / next tab |

Opening the same view twice (say, `:help`) reuses its tab.
