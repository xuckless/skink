Press <kbd>Alt</kbd>+<kbd>S</kbd> (or <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd>, or run `:grep TEXT`) to search every file in the project. Results stream into a tab, grouped by file, and <kbd>Enter</kbd> on a result jumps there.

To replace the matches in every file, run `:greprep WITH`. The changes open in a preview first.

Project search uses the same engine as ripgrep, built in. You do not need `rg` installed.

## Search every file

| Key | Typed command | Does |
|---|---|---|
| <kbd>Alt</kbd>+<kbd>S</kbd> or <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> | `:grep [TEXT]` (`:search`, `:rg`) | Search the project |
| | `:stopsearch` | Stop a search that is still running |

In the search prompt, the same toggles as the find bar apply:

| Key | Toggles |
|---|---|
| <kbd>Alt</kbd>+<kbd>R</kbd> | Regex |
| <kbd>Alt</kbd>+<kbd>C</kbd> | Case-sensitive |
| <kbd>Alt</kbd>+<kbd>W</kbd> | Whole word |

<Aside type="tip">
<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> only reaches Skink in terminals with the kitty keyboard protocol (Ghostty, Kitty, WezTerm, foot and others). <kbd>Alt</kbd>+<kbd>S</kbd> works in most others. Where neither arrives (macOS Option, tmux), type `grep TEXT` after <kbd>Ctrl</kbd>+<kbd>E</kbd>.
</Aside>

### What gets searched

- Every file under the project root, plus any roots you added with `:addroot DIR`.
- `.gitignore` and `.ignore` are honoured, so build output and `node_modules` stay out.
- The search stops at 5000 matches. Narrow the query if you hit that.

### Working with the results

Results are a normal tab, so you can keep them open while you work. After following one, come back with <kbd>Alt</kbd>+<kbd>U</kbd> (jump back, or `:back`).

## Replace in every file

After a search, run:

```text
:greprep NEW_TEXT
```

Skink replaces the last search's matches in every file through the **refactor preview**: a list of files and hunks with checkboxes and a side-by-side diff.

| Key in the preview | Does |
|---|---|
| <kbd>↑</kbd> / <kbd>↓</kbd> | Move |
| <kbd>Space</kbd> | Check or uncheck |
| <kbd>a</kbd> / <kbd>n</kbd> | Check all / none |
| <kbd>Enter</kbd> | Apply the checked changes (one undo step per file) |
| <kbd>Esc</kbd> | Cancel |

In regex mode the replacement can use `$1` for capture groups.

The changed files stay unsaved, so you can look once more before saving.

## Structural search with :sgrep

`:sgrep` searches code by its shape rather than its text, using [ast-grep](https://ast-grep.github.io) patterns. It looks in files of the current file's language. It also works as `:structural`.

In a pattern, `$NAME` matches one syntax node and `$$$NAME` matches any number of them. Whitespace and comments do not matter.

| Command | Finds |
|---|---|
| `:sgrep foo($A, $$$REST)` | Every call to `foo` with at least one argument |
| `:sgrep $X.unwrap()` | Every `.unwrap()` call (Rust) |
| `:sgrep console.log($$$)` | Every `console.log` (JS/TS) |

## Structural rewrite with :srep

`:srep` rewrites every structural match, through the same preview:

```text
:srep foo($A, $B) => bar($B, $A)
```

That turns `foo(x, y + 1)` into `bar(y + 1, x)` everywhere, whatever the spacing or line breaks.

After an `:sgrep`, `:greprep WITH` does the same rewrite with the pattern you searched for. See [Refactoring](/code/refactoring/) for more refactors that use the preview.

## Related searches

- Find a file by name: <kbd>Alt</kbd>+<kbd>P</kbd> or `:recent` (quick open). A `/` in the query matches path segments in order, so `s/c/grade` finds `src/color/grade.rs`.
- Find a symbol: <kbd>Alt</kbd>+<kbd>W</kbd> (`:allsymbols`) searches symbols in the whole project, <kbd>Ctrl</kbd>+<kbd>R</kbd> (`:outline`) in this file.
