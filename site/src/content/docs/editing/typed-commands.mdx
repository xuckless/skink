Every key Skink binds also has a typed command. Press <kbd>Ctrl</kbd>+<kbd>E</kbd>, type the name (for example `comment` or `dotfiles`) and press <kbd>Enter</kbd>.

So when a key never reaches Skink, the action is still one short word away. Nothing needs configuring.

<Aside type="note">
Skink 0.7 had some typed commands, such as `:zoom`, `:recent` and `:fold`. Skink 0.8 added the rest: the short names below, and running any action by its own name.
</Aside>

## Why keys go missing

A terminal editor only sees the keys your terminal passes on. Some chords get lost on the way:

- **macOS:** the Option key types special characters (`∂`, `ß`, `å`) unless the terminal sends it as Alt. See [macOS Option key](/skink/guides/macos-option-key/).
- **tmux and screen:** the prefix key, and some chords they keep for themselves.
- **Windows console:** a few Ctrl and Alt chords arrive as something else, or not at all.
- **Window managers and IDEs:** a desktop shortcut or the IDE's own terminal grabs the chord first.
- **Keyboard layouts:** on non-US layouts, keys like <kbd>/</kbd>, <kbd>\\</kbd> or <kbd>]</kbd> need extra modifiers, so the chord is a different one.

In all these cases, <kbd>Ctrl</kbd>+<kbd>E</kbd> plus the command does the same thing as the key.

## How to type a command

The docs write commands with a colon, like `:dotfiles`. The command line already shows the colon, so you type only the name.

1. Press <kbd>Ctrl</kbd>+<kbd>E</kbd>. The command line opens at the bottom with `:` in place.
2. Type `dotfiles`.
3. Press <kbd>Enter</kbd>.

<kbd>Tab</kbd> completes names, so a few letters are enough. <kbd>Up</kbd> and <kbd>Down</kbd> bring back commands you ran before.

In a terminal tab, <kbd>Ctrl</kbd>+<kbd>E</kbd> goes to the program inside, not to Skink. Press <kbd>F12</kbd> to get back to a file tab first, then type the command.

## Any action by its own name

Every action also runs under the name it has in `bindings.json`, in any spelling. Case, `-` and `_` don't matter, so these three are the same:

- `:ToggleComment`
- `:toggle-comment`
- `:togglecomment`

That covers every action, including ones with no key at all, like `:SortLines` or `:TrimTrailingWhitespace`.

## Look up a key's command in the app

- <kbd>F1</kbd> opens the command palette. Each action shows its key and its typed command as `(:name)`.
- `:help` ends with the full key table: one line per key, with its command beside it.

The same table is on the [Keyboard shortcuts](/skink/reference/shortcuts/) page, in the "Typed command" column.

## Commands worth knowing on macOS

If you'd rather not set up Option as Alt, these get you around without Alt:

| Instead of | Use |
|---|---|
| <kbd>Alt</kbd>+<kbd>P</kbd> quick open | `:recent` |
| <kbd>Alt</kbd>+<kbd>Z</kbd> zoom | `:zoom` |
| <kbd>Alt</kbd>+<kbd>H</kbd> dotfiles | `:dotfiles` |
| <kbd>Alt</kbd>+<kbd>/</kbd> comment | `:comment` |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> next git change | `:nexthunk` |

<kbd>F1</kbd>, <kbd>F5</kbd> / <kbd>F9</kbd> / <kbd>F10</kbd> for debugging and <kbd>Ctrl</kbd>+<kbd>Z</kbd> never need Alt either.
