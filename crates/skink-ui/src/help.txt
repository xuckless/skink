Skink help
==========

Skink is a lightweight, modeless terminal editor. Everything it shows opens as
a tab, the same way a file does: files, this help, command output, git diffs,
merge conflicts, your settings, and terminals.

## Getting started
  skink FILE[:LINE[:COL]]   open a file (jump to a position)
  skink DIR                 open a folder: file tree + empty buffer
  skink                     empty scratch buffer
  Ctrl-E                    command line (type `help` any time; Tab completes)
  Alt-P                     quick open: open tabs, recent files, project files
  Ctrl-Q                    close the tab (quits when it is the last file tab)

## Tabs
  The tab bar is at the top. File tabs and terminal tabs live side by side.
  Click a tab to select it, its x (or middle-click) to close it.
  Alt-1 .. Alt-9            jump to tab N
  Ctrl-PageUp/PageDown      previous / next tab (Alt-, and Alt-. also work in files)
  Ctrl-T                    new empty file tab
  Ctrl-O                    open a file or folder by path
  F12                       toggle between the current file and your terminal tab
  Shift-F12                 open another terminal tab
  F11                       close the active terminal tab
  F8                        file tree (show / move focus / back to the editor)
  Ctrl-B                    hide / show the file tree sidebar
  Terminal tabs show the title set by the program inside, like Ghostty.
  Run an AI agent in one: `:term claude`, `:term gemini`, ...
  In a terminal tab every key goes to the program, except Alt-1..9 and the
  F-keys / Ctrl-PageUp/PageDown that are bound to tab actions (ToggleTerminal,
  NewTerminal, CloseTerminal, ToggleTree, ToggleSidebar, PreviousTab, NextTab), so they can
  be rebound in bindings.json. A finished terminal closes on any key.

## File tree
  Up/Down/PageUp/PageDown/Home/End move, Enter/Right open or expand, Left
  collapses or jumps to the parent, . shows hidden files.
  a  new file in the selected folder ("src/x/y.rs" creates the folders too)
  A  new folder          -  collapse all          *  expand the folder recursively
  r / F2  rename or move (edit the path; new folders are created; open tabs follow)
  d / Delete  move to the OS trash (asks first)
  y  copy the absolute path      Y  copy the path relative to the root
  /  filter files as you type (whole project, .gitignore respected); Esc clears
  < / >  narrower / wider (or drag the right border; actions TreeNarrower / TreeWider)
  q / Esc back to the editor, h hide. Commands: :new PATH, :mkdir PATH,
  :tree collapse | expand | hide.
  Git-ignored entries are dimmed and never auto-expanded. The tree follows the
  active file, remembers open folders per project, and hides itself in
  windows narrower than 50 columns.

## Editing
  Keys follow Micro; the full table is under "Key bindings" below.
  Selection: Shift + movement keys, mouse drag, Ctrl-A (all).
  Scrolling: the wheel scrolls lines; Shift+wheel or a trackpad swipe scrolls
  long lines sideways (the line numbers stay put) until the cursor moves.
  ScrollLeft / ScrollRight are bindable actions.
  Brackets: the pair around the cursor is underlined; Ctrl-] jumps to the other
  one (JumpToMatchingBrace). With syntax, brackets in strings and comments are
  ignored. Terminals without the kitty keyboard protocol send Ctrl-] as Ctrl-5;
  bind it in bindings.json if needed: {"Ctrl-5": "JumpToMatchingBrace"}.
  Undo/redo: Ctrl-Z / Ctrl-Y.   Clipboard: Ctrl-C / Ctrl-X / Ctrl-V
  (Ctrl-C with no selection copies the line, Ctrl-X cuts it).
  Alt-Up / Alt-Down move lines. Ctrl-Shift-D duplicates. Tab / Shift-Tab indent / outdent.

## Lines, case and syntax selection
  Alt-O / Alt-I   grow / shrink the selection to the enclosing syntax node
  :JoinLines  :SortLines  :UpperCase  :LowerCase  :TitleCase  :TrimTrailingWhitespace
  (bind any of them in bindings.json). Case actions work on the selection or
  the word at the cursor; join and sort on the selected lines; all are one
  undo step and run at every cursor.

## Typing helpers
  Brackets and quotes close themselves; typing the closer steps over it,
  Backspace between an empty pair deletes both, and with a selection they wrap
  it. Quotes do not pair inside words (don't). "autoclose": false turns it off.
  Enter after ( [ { indents one level and puts the closer on its own line; a
  closer typed on a blank line goes back one level.
  Tab inserts the file's indentation (tabs or spaces, detected from the file;
  "tabstospaces": true picks spaces for files without indentation yet).
  Alt-/ or Ctrl-/ toggles line comments on the selected lines (ToggleComment),
  using the file type's token (//, #, --, ...).

## Multiple cursors
  Ctrl-D (or Alt-N) selects the word under the cursor; again adds a cursor at
  the next match. Alt-X skips this match, Alt-Shift-Up/Down or Ctrl-Alt-Up/Down
  add a cursor above / below, Alt-click adds or removes one. Esc (or Alt-C)
  goes back to one cursor. Typing, deleting, moving, indenting and moving
  lines happen at every cursor, and one undo undoes them all. Copy with N
  cursors puts one line per cursor on the clipboard; pasting N lines into N
  cursors gives each cursor its own line. The status line shows ×N.
  Actions: SpawnMultiCursor, SpawnMultiCursorUp/Down, SkipMultiCursor,
  RemoveMultiCursor, RemoveAllMultiCursors (Micro's names).
  Ctrl-Shift-D needs the kitty keyboard protocol; elsewhere it arrives as Ctrl-D.
  Ctrl-F opens the find bar: it searches as you type from the cursor, marks
  every visible match and shows "N of M". Alt-R regex, Alt-C case-sensitive
  (default is smart case: lowercase matches any case), Alt-W whole word; the
  active toggles show in the prompt (.* Aa \b). Enter keeps the match, Esc
  goes back to where you were. Ctrl-N / Ctrl-P next / previous match with the
  same options. Ctrl-L go to line.
  :replace FIND WITH replaces every match in the selection (or the whole
  file) as one undo step; quote text with spaces: :replace "a b" "c".

## Views
  Help, command output and git views open as read-only tabs. Opening the same
  view again reuses its tab. `:run CMD` runs in the background in the project
  root (the editor never freezes); the tab fills in when it finishes.

## Files on disk
  Saves are atomic (temp file + rename, permissions and symlinks kept), so a
  crash or full disk never leaves half a file. Encoding is kept as read: UTF-8,
  UTF-8 with BOM, UTF-16 LE/BE; other bytes open read-only (RO) so a save cannot
  corrupt them. :set eol=lf|crlf changes line endings on the next save.
  Changed on disk: clean files reload by themselves (Ctrl-Z undoes); with
  unsaved edits Skink asks: (k)eep mine / (t)ake disk / (d)iff. Saving over a
  file changed since it was read asks first. Checked when the terminal regains
  focus, on tab switches and while you work (at most every 2 s, never idle).
  Unsaved edits are backed up to the state dir after a 3 s pause; after a crash,
  opening the file offers (r)ecover / (d)iscard.
  Permission denied on save: Skink offers sudo and runs `sudo tee` in a
  terminal tab (where sudo can ask for your password); the tab closes once the
  file on disk matches. Files of 2 MB or more open as LARGE: no syntax colours,
  no language server.

## Command line (Ctrl-E)
  Up/Down browse history, Tab completes command names and paths, Esc cancels.
  Any editor action can also be run by name, e.g. `:Save`, `:SelectAll`,
  `:ConflictNext`; see "Actions" below.

## Merge conflicts
  :conflicts      open every file git reports as conflicted, at the first marker
  :nextconflict / :prevconflict   move between <<<<<<< blocks
  :ours / :theirs / :both         resolve the block under the cursor (undoable)
  Conflict blocks are colored: ours (green tint), theirs (blue tint).

## Settings and key bindings
  :settings opens settings.json, :bindings opens bindings.json (created with
  defaults when missing). Save, then run :reload.
  settings.json   {"tabsize": 4, "icons": "auto|nerd|ascii", "syntax": true, "indentguides": true,
                   "updates": "notify|auto|off"}
  bindings.json   Micro format, key name -> action:  {"Ctrl-j": "Save", "Alt-g": "command-edit:goto "}
  Key names: Ctrl-x, Alt-x, Shift-Up, CtrlShiftRight, F5, PageDown, Backtab ...
  Actions can be chained: "Copy|CopyLine" runs the first that works,
  "Escape,Deselect" runs both. "command-edit:TEXT" opens the command line
  pre-filled. Config lives in ~/.config/skink (or $SKINK_CONFIG_DIR).

## Terminals, AI agents and EveryAI
  Terminals are real terminal emulators (colors, mouse, alternate screen), so
  any AI CLI runs unchanged. Inside EveryAI, Skink finds the host through
  SKINK_HOST_URL and SKINK_HOST_TOKEN and hands language servers and agent
  management over to it; the status bar then shows "EveryAI". Without it Skink
  runs language servers itself (rust-analyzer, typescript-language-server,
  basedpyright, gopls, zls when installed).

## Updates
  skink --upgrade          install the latest release in place (also: skink upgrade)
  skink --upgrade --check  only report whether a newer release exists
  skink --upgrade --version 0.1.0   install that release (can downgrade)
  :upgrade                 the same from inside the editor, in the background
  With "updates": "notify" (default) Skink checks GitHub at most once a day and
  says so in the status line; "auto" also installs (used from the next start);
  "off" never checks. SKINK_NO_UPDATE_CHECK=1 or CI turn the check off.
  Installs owned by cargo, Homebrew, scoop or winget print that tool's command.

## Icons and fonts
  Icons are Nerd Font glyphs. The font belongs to your terminal (Ghostty, Kitty
  and WezTerm already include Nerd Font symbols). SKINK_ICONS=ascii or
  "icons": "ascii" in settings.json switches to plain text.
