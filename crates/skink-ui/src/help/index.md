# Help

Skink is a modeless terminal editor: type to edit, keys like any desktop editor.

### Do something

| Key | Does |
|---|---|
| Ctrl-O | open a file or folder |
| Alt-P | quick open: tabs, recent and project files |
| Ctrl-S | save |
| Ctrl-Q | close the tab (quits after the last one) |
| Ctrl-Z / Ctrl-Y | undo / redo |
| Ctrl-F | find and replace in this file |
| Alt-S | search the whole project |
| F1 · F10 | command palette: every action, searchable · menus |
| Ctrl-E | command line: type a command, like `help git` |
| `:help TOPIC` | the help page about anything |
| Ctrl-\ | split side by side |
| F12 | terminal |
