# Previews

Alt-V (or `:preview`) on a Markdown file opens a live, rendered preview in a tab. It follows your edits and opens scrolled to where you were. Alt-V again goes back to the source.

- Headings, emphasis, lists, task lists, quotes, GitHub alerts (`> [!NOTE]`, TIP, IMPORTANT, WARNING, CAUTION), tables, footnotes, rules and syntax-coloured code.
- Tab / Shift-Tab move between links; Enter opens one (web links in the browser, relative ones as files).
- Images show as their alt text.

SVG files preview as half-block pixels: `+` / `-` zoom, `0` resets. Raster images (PNG, JPG) are not previewed yet.

This help is drawn the same way.
